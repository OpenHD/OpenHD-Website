The signal journey

Built as a pipeline. Felt as one system.

The responsibilities stay modular even when the pilot experience feels immediate.

01
CAMERA → ENCODER

See

A platform-specific pipeline captures CSI, USB or IP video and encodes it close to the sensor.
02
PACKETS → RF

Transmit

Video and MAVLink become resilient broadcast traffic with encryption and forward-error correction.
03
RF → NETWORK

Receive

The ground unit rebuilds streams, publishes link health and forwards data to connected clients.
04
DECODE → OSD

Experience

QOpenHD decodes video, layers live telemetry over it and turns settings into MAVLink commands.

Inspect the source

A useful distinction. OHDCommonLib, OHDInterfaceLib, OHDTelemetryLib and OHDVideoLib are linked into a single openhd executable. SysUtils, QOpenHD and the Web UI are separate executables around that core.

Runtime roles

Same core. Different mission profile.

The role is selected at startup; shared code behaves differently at each end of the link.

At altitude

Air unit

openhd --air
  • Discovers camera + encoder
  • Reads flight-controller MAVLink
  • Broadcasts video and telemetry
  • Receives settings and RC uplink
On the ground

Ground unit

openhd --ground
  • Discovers receiving adapters
  • Reconstructs video + data
  • Publishes link statistics
  • Forwards to network clients
In the pilot’s hands

Clients

QOpenHD / Web UI
  • Decodes and displays video
  • Renders configurable OSD
  • Changes settings via MAVLink
  • Connects locally or over IP
Open foundations

Proven libraries. Purpose-built glue.

OpenHD invests engineering effort where generic Linux components stop: deterministic media, broadcast radio and flight-aware control.

Build-time packages also include CMake, a C++ toolchain, autotools and packaging tools. Platform images add patched drivers, codecs and board-specific camera packages as needed.

From source to sky

Choose what you want to build.

Each repository remains independently buildable, while release images bring the complete system together.

OPENHD / BUILD CONSOLEREADY
openhd · C++17 · CMake

Build the core

01
Clone with modules$ git clone --recursive https://github.com/OpenHD/OpenHD.git
02
Install target dependencies$ sudo ./install_build_dep.sh ubuntu-x86
03
Configure & compile$ cd OpenHD && ./build_cmake.sh
Use rpi or rock5 instead of ubuntu-x86 for the matching target environment.
