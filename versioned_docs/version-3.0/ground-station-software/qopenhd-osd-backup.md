# QOpenHD Backup & Restore

Open QOpenHD settings and select **Backup & Restore**.

1. Select **Export** and save the backup file to storage you can access after reinstalling. Review which sections are available on this setup.
2. After installing, select **Import** and open the backup. Review its sections, then select the ones you want and choose **Restore selected settings**.
3. Restart the app if prompted. Check the HUD and any device settings you restored against the running Air and Ground units.

The app’s **Reset** option restores application and OSD defaults on restart. It keeps settings on the connected units. If your build offers FleetControl account backups, they are also available from this dialog.
