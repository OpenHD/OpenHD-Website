# Air recording

1. Open **Manage Air Storage** if your build offers it. Select a recording destination with enough free space. Formatting, preparing, or resizing storage can change the partition layout and may erase data. Back up first.
2. In the QOpenHD sidebar, open **Air recording** and choose the camera. Use manual recording to test the destination. Where offered, automatic mode starts recording when the flight controller arms.
3. Verify that the recording indicator appears. Stop the sample before powering off and play the file back.
4. Retrieve files from the configured destination or via the Air web interface when your image provides recording downloads.

Each available camera can have its own recording mode. Check storage again if recording becomes unavailable or stops unexpectedly.
