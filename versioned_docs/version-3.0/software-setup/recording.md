# Recording

**Air recording** saves the encoded video at the camera side, where it is unaffected by loss over the radio link. **Screen recording** saves what your Ground device displays, including its HUD if visible, and reflects any reception interruptions.

| Goal | Workflow |
| --- | --- |
| Save a clean local stream | Select the Air recording destination, then set recording mode for the camera. See [Air recording](../advanced-setup/air-recording.md). |
| Save the OSD and received picture | Use the display device’s screen recorder. Confirm its frame rate and audio source with a short sample first. |
| Archive both | Verify that each recorder produces a playable file before flying. Use a short bench recording to check available storage and load. |
