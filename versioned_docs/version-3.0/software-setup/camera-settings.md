# Camera and video settings

In QOpenHD, open the sidebar and choose **Video** to set the stream format, codec, rotation, or bitrate when available. Start with a format supported by the camera driver and Ground decoder. A change may restart the Air stream briefly.

Open **Camera** or the Air camera settings for sensor controls such as exposure, gain, white balance, and image adjustments. The selected camera and backend determine which controls are writable. Use the image reset action, where available, to restore picture adjustments without changing the stream format or link.

Test one setting at a time and watch the live picture and receiver statistics. If the picture disappears, restore the last working stream format before changing radio settings.
