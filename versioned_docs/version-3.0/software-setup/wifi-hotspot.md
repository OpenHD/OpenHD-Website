# Wi-Fi hotspot

Enable the OpenHD hotspot only on a supported interface. Open the connected unit’s network settings and select the hotspot mode and, where exposed, its interface. Check which interface is carrying the primary OpenHD link before selecting one.

Use the SSID and password configured on your device. If ImageWriter exposes initial hotspot settings for the selected build, you can set these before first boot. In automatic mode the hotspot can stop when the flight controller arms.

Connect the client and verify the Ground unit is reachable. Use [tethering](./tethering.md) to test what the selected image forwards over that connection.
