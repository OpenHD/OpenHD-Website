# Albatross features

| Area | What to use |
| --- | --- |
| Link setup | The QOpenHD sidebar exposes link controls and **Find Air Unit**. Check whether your image and radio offer 10, 20, or 40 MHz. |
| Video | Start with one camera and a supported encode and decode combination. Check the Air image for secondary camera and recording support. |
| RC assignments | Inspect live PWM in QOpenHD and configure range-based assignments when the Air build exposes them. |
| Ground display | QOpenHD provides a configurable HUD, maps, and local sound and speech settings. |
| Configuration | ImageWriter can prepare initial device settings. QOpenHD can edit the capabilities exported by the running units and back up selected settings. |

See [QOpenHD](../ground-station-software/qopenhd.md), [Air recording](../advanced-setup/air-recording.md), [RC link controls](../software-setup/mcs-via-rc.md), and [offline maps](../ground-station-software/offline-maps.md).
