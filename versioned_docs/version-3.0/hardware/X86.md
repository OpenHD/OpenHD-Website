# x86 Ground

Albatross ImageBuilder has separate **x86 minimal** and **x86 Noble** targets. Check which Ground client and desktop the selected image includes. Use the storage and boot method provided for that image.

1. Attach a supported radio with antennas and connect the display.
2. Boot the Ground system and verify that it detects the link radio.
3. Start the Ground client and check the Ground unit status.
4. Confirm decode and display with the codec and stream resolution you plan to use.

If using a second client on the same network, check [tethering](../software-setup/tethering.md) after the local Ground client works.
